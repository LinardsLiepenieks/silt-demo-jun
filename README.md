# Windmill

A recreation of the [gowindmill.com](https://gowindmill.com/) landing page. It's a demo project for Silt, so each section is its own reusable component.

```
npm install
npm run dev
```

Sections live in `src/components/`, their copy and data in `src/content/`, and design tokens in the `@theme` block of `src/index.css`. The hero layers and Sarah's journey share one slideshow hook in `src/lib/`.

This is an unofficial recreation, not affiliated with Windmill. The Windmill name, logo, product imagery, photography, video and customer logos belong to Windmill and their respective owners.
